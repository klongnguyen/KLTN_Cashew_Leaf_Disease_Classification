# EXP-033 validation figures

Generated from aggregate CSVs without fitting or selecting any parameters.

Wilson intervals describe single-rule accuracy. The paired bootstrap figure shows the 95% interval of each rule's difference from F0. Holdout figures are descriptive audits, not blind benchmarks. Localization uses labeled YOLO Test only; Holdout has no box ground truth. The risk–coverage curves sweep thresholds for illustration and do not retune the frozen abstention threshold. The ECE bar chart summarizes calibration error; a reliability diagram requires per-image calibrated probabilities, which the aggregate tables do not retain.
